Visual intent

A Pixel client for the Herdr runtime on this Omarchy box — not a shrunken SSH TUI, not a vendor chat app. Colors come from the theme that’s on right now.

  • Accent is attention: blocked agents, allow, the thing that needs you.
  • Green is structure: live connection, working, the machine is fine.
  • Home is the herd. A session is chat-first. Terminal is a toggle, not the product.
  • Approvals are buttons with the command in monospace — never a raw y/n in a tiny PTY.
  • Palette is your current Omarchy theme. Switch theme, then refresh this tab (or run sync-theme.sh).
